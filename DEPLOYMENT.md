# 🚀 Shelfy 🇹🇿 Deployment & Environment Variables Guide

This guide walks you through deploying **Shelfy 🇹🇿** directly on **Railway** (or Google Cloud Run, Render, VPS).

---

## 🔑 Environment Variables & Secrets Required

When deploying to **Railway** (or any cloud host), set the following variables in the **Variables / Secrets** dashboard:

| Variable Name | Required? | Description & Recommended Value |
| :--- | :--- | :--- |
| `NODE_ENV` | **Yes** | `production` |
| `PORT` | **Optional** | Automatically set by Railway (defaults to `3000`) |
| `JWT_SECRET` | **Yes** | A long random string for JWT authentication. If missing, the app still boots with a temporary secret (sessions reset on each deploy). |
| `GEMINI_API_KEY` | **Yes** | Your Google Gemini API Key (from Google AI Studio) for AI Shelf Auditing, AI ShelfMatch, and Insights. |
| `APP_URL` | **Yes** | The public URL generated by Railway (e.g. `https://your-shelfy-app.up.railway.app`) |
| `PESAPAL_CONSUMER_KEY` | Optional | Your PesaPal v3 Consumer Key for live/sandbox payments |
| `PESAPAL_CONSUMER_SECRET` | Optional | Your PesaPal v3 Consumer Secret for live/sandbox payments |
| `PESAPAL_ENVIRONMENT` | Optional | `sandbox` (for testing) or `live` (for production) |

## 🚂 Option 1: Deploy to Railway (Step-by-Step)

1. **Push your Code to GitHub**:
   - In Google AI Studio, click the **Settings / Export** icon and choose **Export to GitHub** (or download the ZIP and push to your GitHub repo).

2. **Create a Project on Railway**:
   - Go to [Railway.app](https://railway.com/) and log in.
   - Click **+ New Project** → **Deploy from GitHub repo**.
   - Select your Shelfy repository.

3. **Add Environment Variables in Railway**:
   - Go to the **Variables** tab of your service.
   - Add the following keys:
     - `NODE_ENV` = `production`
     - `JWT_SECRET` = `shelfy_secret_key_tz_2026`
     - `GEMINI_API_KEY` = `your_gemini_api_key`
     - `APP_URL` = `https://${{RAILWAY_PUBLIC_DOMAIN}}`
     - `PESAPAL_ENVIRONMENT` = `sandbox`

4. **Generate Public Domain**:
   - Go to the **Settings** tab on Railway → **Networking** → Click **Generate Domain**.
   - Your app will be live with HTTPS!

**Demo accounts** (after deploy): `admin@shelfy.co.tz`, `vendor@shelfy.co.tz`, `host@shelfy.co.tz`, `agent@shelfy.co.tz` with password `Password123!`.

**Persistence note:** the current app stores data in `data/shelfy.json`. Railway's filesystem is ephemeral unless you attach a volume. The `shelfy` Railway project also has a Postgres service that the app does **not** use yet — either attach a volume for the JSON file or migrate to Postgres before treating this as production data.

Railway uses the included `railway.json` or `Dockerfile` automatically:
- **Build Command**: `npm run build`
- **Start Command**: `npm start` (or `node dist/server.cjs`)
- **Health Check Endpoint**: `/api/health`

## ⚡ Option 2: 1-Click Deploy in Google AI Studio

You can also deploy directly inside Google AI Studio:
1. Look at the top right of the Google AI Studio screen.
2. Click the **Deploy** button.
3. Your applet will deploy instantly to a scalable Google Cloud Run container.
